01 / Start here

What is a Claude skill?

An instruction file

A skill is a short document, called SKILL.md, that teaches Claude how to do one job well, such as auditing a website or building a monthly report.

Installed once

Once a skill is installed, Claude uses it automatically whenever the task comes up. You don't repeat your instructions in every chat.

Consistent results

The same steps run every time, so this month's report looks like last month's and the two can be compared.

Before you start: these skills run in Claude Code. Commands marked In Claude Code are typed into Claude Code itself. Commands marked In your terminal go into Command Prompt, PowerShell or Terminal.

02 / Recommended

Five skills worth installing

These are built and maintained by other teams. We list each one by the business job it does. The install commands use the original projects, so you always get the latest version, and Axia keeps a copy of each one on its GitHub.

Automate the officeby Google Workspace

Google Workspace CLI

Lets Claude work inside Gmail, Drive, Sheets, Docs and Calendar. It comes with more than 100 ready-made skills, one for each Google service, plus common workflows.

Example: "Every Monday, pull last week's sales from the Sheet, summarise them and draft an email to the branch managers."

Active · updated Oct 2026Needs Node.js 18+ and a Google accountPre-1.0: last release Mar 2026
In your terminal
npm install -g @googleworkspace/cli
gws auth setup
npx skills add https://github.com/googleworkspace/cli

Original: googleworkspace/cli · Axia copy: Sharonmaganga/google-workspace-cli

Get found onlineby Daniel Agrici

Claude SEO

Audits your website for technical SEO, schema markup, local search and AI search visibility, then helps you fix what it finds. It has 26 specialist sub-skills.

Example: "Audit our site for local SEO in Nairobi and Kampala and list the ten fixes with the biggest impact."

Active · updated Oct 2026MIT licence
In Claude Code
/plugin marketplace add AgriciDaniel/claude-seo
/plugin install claude-seo@agricidaniel-claude-seo

Original: AgriciDaniel/claude-seo · Axia copy: Sharonmaganga/claude-seo

Search your documentsby Graphify Labs

Graphify

Turns a folder of policies, SOPs, PDFs, database schemas or code into a knowledge graph, so Claude can answer questions about them without re-reading everything each time.

Example: "Which of our credit policies mention collateral for loans above KES 500,000?"

Active · updated Oct 2026Needs Python 3.10+
In your terminal
pip install graphifyy && graphify install

On Windows, if graphify isn't recognised after installing, use pipx install graphifyy instead.

Original: Graphify-Labs/graphify · Axia copy: Sharonmaganga/graphify

Look professionalby Next Level Builder

UI/UX Pro Max

Gives Claude a library of design styles, colour palettes and font pairings, so dashboards, client portals and landing pages look professionally designed.

Example: "Redesign our member portal dashboard to look clean and trustworthy on a phone."

Active · updated Oct 2026MIT licence

Tell the storyby Remotion

Remotion

Creates videos from code: product demos, explainers and animated charts. Because each video is generated from data, you can re-render it every month with new numbers.

Example: "Make a 30-second animated summary of this quarter's results for LinkedIn."

03 / Built by Axia

Two skills made for how African businesses work

The skills above are general-purpose. We wrote these two for the reporting and planning work our clients do every month. They're free and open source.

monthly-kpi-report

Monthly KPI report

Turns sales, finance or loan data into a one-page management report. It suggests KPIs for your sector, such as PAR 30 for SACCOs and gross margin for retail, and marks each one on track, watch or action needed.

ai-opportunity-audit

AI opportunity audit

Asks about your processes, scores each one for automation potential and gives you a 30, 90 and 180-day roadmap. It includes a data protection note for your country.

04 / Questions

Common questions

Do I need to be a developer?

No, but you do need to be comfortable copying a command into a terminal. If you'd rather not, we can install and set up these skills for your team.

Is my data safe?

The files Claude reads are handled under your Claude account's data settings. Some skills also connect to other services, such as Google Workspace, so check what each one accesses before you install it. For customer, member or health records, agree a data policy first. Our AI opportunity audit includes one.

Are these skills free?

Yes. All seven skills are free and open source. You need a Claude plan to run Claude Code, and some skills need Node.js or Python installed.

How do you keep this list current?

We re-check every repository, link and install command before each update and show the date at the top of this page. Skills change quickly, so if a project's own README differs from what's here, follow the README.

Third-party skills belong to their authors and are listed with credit. Axia Analytics isn't affiliated with Anthropic, Google or the projects listed.
